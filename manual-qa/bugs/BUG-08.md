# BUG-08. Валидация формы добавления оборудования не запускается

| Поле | Значение |
|---|---|
| Severity | Medium |
| Priority | High |
| Статус | Open |
| Метод подтверждения | Анализ кода: `lib/features/owner/screens/add_equipment_screen.dart:27, 63-88, 133-198` |
| Тест-кейсы | TC-OWN-02, TC-OWN-03 |

## Шаги воспроизведения (UI)

1. Открыть «Добавить оборудование».
2. Оставить название/описание пустыми, ввести цену `-100`, депозит `-50`, выбрать локацию.
3. Нажать «Сохранить».

## Фактический результат

Создаётся карточка с пустыми полями и отрицательными ценами. При пустой цене вместо ошибки поля показывается общий SnackBar `Ошибка: FormatException: Invalid double`.

## Ожидаемый результат

Inline-ошибки валидации у полей, запись не создаётся.

## Доказательство в коде

`_formKey` объявлен, но в `_saveEquipment()` нет вызова `_formKey.currentState!.validate()`; validators определены только в виджетах.

## Влияние

В каталог попадают некорректные данные, которые ломают сортировку и расчёт цены.

## Рекомендация

Вызвать валидацию формы до записи; добавить проверки `pricePerHour > 0`, `depositAmount >= 0`; показывать ошибку у конкретного поля.
