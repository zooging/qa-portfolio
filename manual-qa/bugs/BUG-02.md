# BUG-02. Статус equipment «booked» выставляется навсегда и блокирует весь инвентарь

| Поле | Значение |
|---|---|
| Severity | High |
| Priority | High |
| Статус | Open |
| Метод подтверждения | Анализ кода: `lib/data/services/booking_service.dart:112-123, 259-264, 387-421`; `lib/features/equipment/screens/equipment_detail_screen.dart:255-265` |
| Тест-кейсы | TC-BKG-05, TC-OWN-06 |

## Шаги воспроизведения (UI)

1. Пользователь A бронирует вещь на 1 час завтра.
2. Пользователь B открывает ту же карточку и пытается забронировать её на другую неделю.
3. Владелец отклоняет бронь A и проверяет карточку снова.

## Фактический результат

После создания брони в документе equipment пишется `status: 'booked'` (вся вещь, а не интервал). `updateBookingStatus`, `completeBooking` и `cancelBooking` не сбрасывают этот статус. Кнопка «Арендовать» (`isEnabled: false`) недоступна до ручного переключения владельцем.

## Ожидаемый результат

Занят только интервал брони; после отклонения/отмены/завершения вещь снова `available`.

## Доказательство в коде

```dart
transaction.set(bookingRef, booking);
transaction.update(equipmentDoc.reference, {'status': 'booked'});
```

## Влияние

Два независимых дефекта: ложная недоступность на другие даты и «залипший» статус после завершения аренды.

## Рекомендация

Хранить занятые интервалы в подколлекции `bookings` и считать доступность по пересечению дат; обновлять статус equipment во всех переходах жизненного цикла брони.
