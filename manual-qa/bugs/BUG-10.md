# BUG-10. Диалог «Связаться с владельцем» всегда пустой

| Поле | Значение |
|---|---|
| Severity | Medium |
| Priority | Medium |
| Статус | Open |
| Метод подтверждения | Анализ кода: `lib/features/booking/screens/booking_status_screen.dart:339-356`; `lib/data/services/booking_service.dart:99-109, 189-200`; `lib/data/models/rental_booking.dart:9-10, 23-24` |
| Тест-кейс | TC-PRF-04 |

## Шаги воспроизведения (UI)

1. Подтверждённая бронь → «Статус бронирования» → «Связаться».

## Фактический результат

Пустой диалог только с кнопкой «Закрыть»: `ownerPhone`/`ownerEmail` не записываются при создании брони и не маппятся при чтении.

## Ожидаемый результат

Телефон и email владельца (или переход к чату).

## Влияние

Клиент не может связаться с владельцем — заявленный сценарий взаимодействия не работает.

## Рекомендация

Денормализовать контакты владельца в документ `bookings` при создании и маппить их в `getBookingStream`, либо явно открывать чат.
