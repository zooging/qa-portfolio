# BUG-06. Продление аренды не проверяет дату и пересечения, не пересчитывает цену

| Поле | Значение |
|---|---|
| Severity | Medium |
| Priority | Medium |
| Статус | Open |
| Метод подтверждения | Анализ кода: `lib/features/rental_history/screens/rental_detail_screen.dart:44-71`; `lib/data/services/booking_service.dart:375-385` |
| Тест-кейс | TC-BKG-09 |

## Шаги воспроизведения (UI)

1. Открыть активную аренду → «Продлить аренду».
2. Выбрать дату раньше текущего `endDate` либо дату, на которую уже есть другая бронь.

## Фактический результат

`endDate` перезаписывается без проверок (в том числе на полночь выбранной даты), стоимость не меняется, пересечения не проверяются.

## Ожидаемый результат

Нельзя сократить аренду или занять чужой слот; итоговая цена пересчитывается.

## Доказательство в коде

```dart
await _firestore.collection('bookings').doc(bookingId).update({
  'endDate': Timestamp.fromDate(newEndDate),
  'lastUpdated': Timestamp.fromDate(DateTime.now()),
});
```

## Влияние

Порча данных аренды и финансовые потери.

## Рекомендация

Перенести продление в `BookingService` с валидацией `newEndDate > currentEndDate`, проверкой пересечений и пересчётом суммы в транзакции.
