# BUG-04. Pending-бронирование показывается как активное с кнопками управления

| Поле | Значение |
|---|---|
| Severity | High |
| Priority | High |
| Статус | Open |
| Метод подтверждения | Анализ кода: `lib/data/services/booking_service.dart:348-361`; `lib/features/rental_history/screens/rental_detail_screen.dart:226-243`; `lib/data/models/rental_status.dart:11-16` |
| Тест-кейсы | TC-BKG-10, TC-PRF-02 |

## Шаги воспроизведения (UI)

1. Создать бронь (статус `pending`, владелец ещё не ответил).
2. Профиль → История аренд → открыть карточку.

## Фактический результат

Маппинг в сервисе превращает `pending` в `confirmed`. В карточке доступны «Продлить аренду», «Завершить аренду», «Отменить аренду»; запись попадает в фильтр «Активные».

## Ожидаемый результат

Статус «Ожидает подтверждения», кнопки завершения/продления скрыты, в активные не попадает.

## Доказательство в коде

```dart
case 'pending':
  return 'confirmed'; // Pending заказы тоже показываем как активные
```

## Влияние

Клиент может «завершить» аренду, которая ещё не одобрена; данные истории не соответствуют реальному статусу.

## Рекомендация

Не маппить `pending` в `confirmed`; добавить отдельный статус UI «pending» и явно перечислять статусы, для которых доступны действия.
