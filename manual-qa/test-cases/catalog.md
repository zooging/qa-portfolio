# Тест-кейсы: каталог, поиск и фильтры

### TC-CAT-01 — Просмотр каталога
- **Требование:** FR-03 (строка 638) · **Приоритет:** High
- **Шаги:** 1) Открыть приложение без авторизации. 2) Перейти в каталог.
- **Ожидаемо:** список инвентаря с названием, ценой и статусом; загрузка ≤ 3 с.
- **Статус:** Planned.

### TC-CAT-02 — Поиск по названию
- **Требование:** FR-04 (строка 639) · **Приоритет:** High
- **Шаги:** 1) Ввести «Лыжи» в строку поиска. 2) Проверить выдачу.
- **Ожидаемо:** только позиции с «Лыжи» в названии.
- **Статус:** Planned.

### TC-CAT-03 — Сортировка по цене
- **Требование:** FR-04 · **Приоритет:** Medium
- **Шаги:** 1) Выбрать «Сначала дешёвые». 2) Выбрать «Сначала дорогие».
- **Ожидаемо:** список перестраивается по возрастанию, затем по убыванию цены.
- **Статус:** Static: FAIL → A1 (два разных `sortOptionProvider`).

### TC-CAT-04 — Сортировка «Сначала новые»
- **Требование:** FR-04 · **Приоритет:** Low
- **Шаги:** 1) Добавить новый инвентарь. 2) Выбрать сортировку «Сначала новые».
- **Ожидаемо:** новая позиция первая.
- **Статус:** Static: FAIL → A1 (`createdAt` не записывается).

### TC-CAT-05 — Фильтр по категории на главном экране
- **Требование:** FR-04 · **Приоритет:** Medium
- **Шаги:** 1) Выбрать категорию «Велосипеды». 2) Проверить список.
- **Ожидаемо:** отображаются только велосипеды.
- **Статус:** Static: FAIL → A2 (`updateCategory` не вызывается).
