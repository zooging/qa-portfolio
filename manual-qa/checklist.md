# Чек-лист: smoke и регресс (50 проверок)

Обозначения: **[S]** smoke (обязателен перед каждым прогоном), **[R]** regression, **[N]** негатив.

## Smoke — доступность и навигация

| ID | Тип | Проверка | Ожидаемый результат |
|---|---|---|---|
| CHK-001 | S | Запуск приложения, главный экран | Экран загружается ≤ 3 с, каталог/категории видны |
| CHK-002 | S | Регистрация нового пользователя | Запись создана в `users`, вход выполнен |
| CHK-003 | S | Вход с корректными данными | Открывается главный экран, роль клиента определена |
| CHK-004 | S | Вход с неверным паролем | Понятное сообщение об ошибке, нет перехода в приложение |
| CHK-005 | S | Выход из аккаунта | Возврат на экран входа, сессия сброшена |
| CHK-006 | S | Открытие каталога | Список инвентаря не пуст, карточки отображают цену |
| CHK-007 | S | Поиск по названию | Выдаются только подходящие позиции |
| CHK-008 | S | Открытие карточки инвентаря | Название, описание, цена, фото, кнопка «Арендовать» |
| CHK-009 | S | Открытие экрана бронирования | Выбор дат и расчёт стоимости доступны |
| CHK-010 | S | История аренд | Экран открывается, список/пустое состояние корректны |
