# BUG-009. Невалидная дата в фильтре вызывает 500

| Поле | Значение |
|---|---|
| Severity | Minor |
| Priority | Low |
| Status | Open |
| Environment | https://restful-booker.herokuapp.com, 27.11.2026 |
| Тип | Обработка ошибок / валидация входа |

## Шаги воспроизведения

1. Выполнить `GET /booking?checkin=not-a-date`.

## Фактический результат

`500 Internal Server Error`, тело `Internal Server Error`.

## Ожидаемый результат

`400 Bad Request` с сообщением о некорректном формате даты (ожидается `YYYY-MM-DD`).

## Почему это важно

Ошибка пользовательского ввода маскируется под серверный сбой, что мешает разбору логов и метрик ошибок.

## Тест-свидетель

`tests/test_booking_search.py::test_filter_invalid_date_returns_400`

## Предложение по исправлению

Валидировать формат query-параметров до обращения к БД, возвращать 400 с понятным сообщением.
