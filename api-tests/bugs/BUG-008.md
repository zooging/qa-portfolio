# BUG-008. Фильтр `checkout` игнорируется

| Поле | Значение |
|---|---|
| Severity | Major |
| Priority | High |
| Status | Open |
| Environment | https://restful-booker.herokuapp.com, 27.11.2026 |
| Тип | Поиск / фильтрация |

## Шаги воспроизведения

1. Создать бронирование с уникальной датой `checkout`, например через 705 дней от текущей.
2. Выполнить `GET /booking?checkout=<эта дата>`.

## Фактический результат

`200 OK` и ~2360 бронирований — фактически весь список, хотя с такой датой выезда создано одно бронирование.

## Ожидаемый результат

Список из одного (или нескольких) бронирований с указанной датой выезда.

## Почему это важно

Фильтр не уменьшает выдачу: клиент получает лишние данные, растёт нагрузка на сеть и БД, возможны ошибки в аналитике.

## Тест-свидетель

`tests/test_booking_search.py::test_filter_by_checkout` (ожидает не более 10 результатов)

## Предложение по исправлению

Добавить условие фильтрации по `checkout` в запрос к БД; покрыть тестом с уникальной датой.
